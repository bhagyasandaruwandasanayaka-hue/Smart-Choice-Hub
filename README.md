# S U P I R I - Premium E-Commerce Website

Meka oya illapu "Supiri" e-commerce website eka. Node.js nathiwa, HTML, CSS (Tailwind), saha JavaScript walin hadala thiyenne.

## Features
- **Modern Design**: Glassmorphism, Neon effects, Dark mode.
- **Fully Responsive**: Phone, Tablet, PC ona ekaka wada.
- **Product Management**: `assets/js/items.js` file eke products wenas karanna puluwan.
- **Cart System**: Items cart ekata add karanna, remove karanna puluwan (Storage browser eke save wenawa).
- **Search & Filter**: Products category anuwa filter karanna puluwan.

## Kohomada Run Karanne?
1. `index.html` file eka kelinma browser eke open karanna (Double click).
2. Nathnam VS Code wala "Live Server" extension eka use karanna (wada hodai).

## Files Walata Visthara
- `index.html`: Home page eka.
- `shop.html`: Badu okkoma thiyena page eka.
- `product.html`: Thanikara baduwak gana wisthara.
- `cart.html`: Cart eke thiyena dewal.
- `contact.html`: Contact form eka.
- `assets/js`: Script files (Logics).

Supiriyatama hadala thiyenne, poddak balanna!
